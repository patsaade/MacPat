# The interface is a 1-bit style, drawn from scratch

The look nods to 1980s desktop software: black on white, swapped for dark mode, with striped title bars and hard shadows. We draw it ourselves with SwiftUI shapes and the system monospaced font. We do not copy Apple's icons, bitmaps, or typefaces, which are protected. A style is free to borrow, assets are not. Cost: custom controls need their own accessibility work, so each one is a real Button underneath and carries the right traits.
