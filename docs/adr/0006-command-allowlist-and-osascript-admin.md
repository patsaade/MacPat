# Commands come from a typed allowlist; admin goes through osascript

MacPat needs a few system tools, such as `launchctl`, `tmutil`, and `pkgutil`, and some of them need root. Every command is a `Command` value that only its factories can build. Each factory fixes the program path and the arguments and checks the parts that vary against a strict pattern. Only `Exec.swift` may start a process, and CI enforces it. Admin steps go through `osascript ... with administrator privileges`, so macOS shows its own prompt each time. This amends [0004](0004-per-action-admin-prompt.md): "per action" means per run, and macOS caches the password for a few minutes. Rejected: a resident privileged helper, which is a standing attack surface; `AuthorizationExecuteWithPrivileges`, which is deprecated. Cost: macOS runs the admin line through `sh`, so quoting must stay right. Tests feed shell metacharacters to every factory.
