# Remove a persistence item

1. Open **Persistence**.
2. Pick an action. **Disable** stops the job and keeps it from starting, and the file stays. **Remove** stops it and moves its file to the Trash. **Re-enable** lists jobs you disabled.
3. Open a group and read the reason. Orphans are safe: their program is gone. Unusual items need a look, not panic.
4. Tick what you want gone. Click **Preview**, then the action button.
5. For a system daemon, macOS asks for your password.

To undo a Disable, switch to **Re-enable**. To undo a Remove, put the file back from the Trash and log out and back in.

Items inside apps, Apple's own items, and anything under **Startup places MacPat only shows** say where to turn them off by hand. **Deep Scan…** reads the full Login Items list. It needs your password, and it only reads.
