# Run an optimize task

These fix specific problems. None of them makes a healthy Mac faster, so nothing is ticked by default.

1. Open **Optimize** and read the cost and undo line for each task.
2. Tick the one that matches your problem. **Show commands** shows exactly what runs.
3. **Preview**, then **Run…**. Admin tasks ask for your password.

| Problem | Task |
| --- | --- |
| A site moved but your Mac still finds the old one | Flush the DNS cache |
| Open With lists apps twice, or a default app is wrong | Rebuild the Launch Services database |
| Previews are blank or stale | Reset the Quick Look cache |
| Spotlight misses files | Rebuild the Spotlight index |
| Deleted files still take space | Delete local Time Machine snapshots |
