# Uninstall an app

1. Quit the app. A running app is locked.
2. Open **Uninstall** and pick the app, or drop it on the list.
3. Read the groups. Files named after the app's bundle ID are ticked. Files shared with the same developer, or matched by name only, are not. Check those yourself.
4. **Starts at login** lists the app's launch jobs. They are stopped and moved with it.
5. **Preview**, then **Move to Trash…**.

**Orphaned files** at the top of the list are guesses. Each one is named like an app that macOS doesn't know about any more. Some belong to command-line tools or helpers, so review each one.
