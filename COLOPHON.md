# Colophon

- **Language:** Swift 6, strict concurrency.
- **Interface:** SwiftUI, with Liquid Glass from the system.
- **Type:** the system font, SF Pro. Nothing is bundled.
- **Art:** vector only. The paw is a SwiftUI path. Symbols are SF Symbols. No bitmaps are committed.
- **Build:** Xcode, XcodeGen, Swift Package Manager.
- **Tests:** Swift Testing.
- **Docs:** structured with Diátaxis.
- **Made by:** Patrick Saade. Claude, an AI model from Anthropic, wrote most of the first version of the code and docs.
- **Look:** a 1-bit, 1980s-desktop style. Pure ink on pure paper, swapped in dark mode, following the system setting. Windows have striped title bars, heavy outlines, and hard shadows. It is drawn from scratch with shapes and the system monospaced font. No Apple artwork, icons, or typefaces are used or copied.
