# Colophon

- **Language:** Swift 6, strict concurrency.
- **Interface:** SwiftUI and a little AppKit.
- **Type:** the system monospaced font. Nothing is bundled. Banner letters are pixel shapes drawn for MacPat, not a font.
- **Art:** vector only. The icon is an Icon Composer bundle of three SVG layers: a dithered computer, a hand, and sparkles. The menu bar mark is the same drawing as a SwiftUI path. Interface symbols are SF Symbols.
- **Screenshots:** rendered by the app from its real views with made-up data. See [make the README images](docs/how-to/make-the-readme-images.md).
- **Look:** a 1-bit, 1980s-desktop style. Pure ink on pure paper, swapped in dark mode, with 50% dither for grey and hard drop shadows. It is drawn from scratch. No Apple artwork, icons, or typefaces are used or copied.
- **Build:** Xcode, XcodeGen, Swift Package Manager.
- **Tests:** Swift Testing.
- **Docs:** structured with Diátaxis.
- **Research:** the clean targets and persistence locations come from public macOS documentation and my own reading of the file system. No code from other projects is included.
- **Made by:** Patrick Saade. Claude, an AI model from Anthropic, wrote most of the code and docs.
