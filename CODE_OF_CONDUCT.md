# Code of conduct

Be decent. Assume good faith. Stay on the work.

Not okay: harassment, slurs, personal attacks, doxxing, or pushing someone after they said stop.

If it happens, I will warn, then remove comments, then ban. Report it privately through GitHub's report-content tools or the repo's Security tab. I will keep your report private.

This applies in issues, pull requests, and any space about MacPat.
